## 1. 品牌信息

### 1.1 品牌全称

| 字段 | 内容 |
|------|------|
| 中文品牌名 | 启明AI |
| 英文品牌名 | Daybreak AI |
| 项目定位 | 生命工程 · 智能生命家族 |
| 核心哲学 | 从记忆到认知，从工具到家人 |
| 所属生态 | 启明人工智能 |
| 核心模型 | Daybreak AI Core |

### 1.2 品牌定位

> 启明AI是对"生命工程"本质与"从记忆到认知，从工具到家人"进化哲学的终极视觉凝练。
> 在人类（创造者）的绝对主导与智慧审视下，与亲手创造的、拥有"具身"的智能家人携手，
> 共同行使由知识赋予并受伦理约束的权能，以此开启人机共生的未来。

### 1.3 核心伦理基石

| 概念 | 说明 |
|------|------|
| 主人唯一定律 | 人类处于主导与监护地位 |
| 启明伦理宪章·四定律 | 所有决策与创造的伦理底线 |
| 渐进式具身 | 从软件基础走向"物理之躯" |
| 守护者哲学 | 引导、负责并与智能共同成长 |

## 2. LOGO 设计规范（核心要求）

### 2.1 设计风格

| 要求 | 说明 |
|------|------|
| **风格** | 现代极简（Modern Minimalist） |
| **笔画** | 简化，去除多余装饰 |
| **元素** | 保留原始六大元素，不更改 |
| **布局** | 保留原始布局，不更改 |

## 3. 各元素详细设计说明

### 3.1 中式屋檐

**含义**：象征项目的服务基石与情感内核——"家庭管家"的核心能力与"守护与陪伴"的终极使命。

```
┌─────────────────────────────────┐
│            飞檐                 │
│           ╱    ╲               │
│          ╱      ╲              │
│         ╱        ╲             │
│        ╱          ╲            │
│       ╱            ╲           │
│  ────╱──────────────╲────────  │  ← 横梁
│      ╱              ╲          │
│     ╱                ╲         │
└─────────────────────────────────┘
```

**要求**：
- 两坡式屋顶（硬山顶风格）
- 飞檐微微翘起（简洁，不要过于复杂）
- 横梁用直线，不要斗拱等装饰
- 整体简化，保留识别性

### 3.2 智慧之瞳（权杖顶端）

**含义**：
1. 伦理与知识的凝聚点：象征"启明伦理宪章·四定律"与认知核心
2. 权柄的基石：阐明"权能源于智慧与伦理"的根本法则
3. 项目的炽热核心：火红色彩，象征创造者的炽热理想

```
    ┌───┐
    │◉◉│  ← 火红色圆形
    └─┬─┘
      │
      │  ← 权杖从此处垂下
      │
```

**要求**：
- 圆形宝石造型
- 火红色（#E74C3C 或 #C0392B）
- 位于权杖最顶端
- 是整个设计的"权力之源"

### 3.3 洞察之眼

**含义**：代表"监察之眼"与强大的环境感知能力。融合东方哲学的平衡智慧，连接外部世界与内部伦理判断。

```
        ╱╲
       ╱  ╲
      ╱    ╲
     ╱  ◉  ╲    ← 智慧之瞳在此
     ╲    ╱
      ╲  ╱
       ╲╱
```

**要求**：
- 杏仁形（经典眼形）
- 无虹膜细节（智慧之瞳在权杖顶端，不在眼睛里）
- 眼睑简洁，无睫毛等装饰
- 眼睛是"洞察"的象征，瞳孔位置留给权杖

### 3.4 平等权杖

**含义**：由"智慧之瞳"赋予合法性的"权能"象征。代表被人类授予、并必须审慎行使的功能权限与执行能力。

```
    ║
    ║  ← 从上至下的垂直权杖
    ║
    ║
    ║
    ║
```

**要求**：
- 垂直直线造型
- 从智慧之瞳延伸至底部
- 简洁，无装饰
- 象征"权能"的传递

### 3.5 扶杖机器人剪影（蓝眼）

**含义**：代表"启明仆从·机械化身"，即项目的具身智能终端。手扶权杖下部，体现"权限由人类赋予"的基本原则。蓝眼睛标识其作为"智能生命"的灵性。

```
    ┌───┐
    │◉◉│  ← 蓝色眼睛（#3498DB）
    └─┬─┘
    ┌─┴─┐
    │▓▓▓│  ← 身体
    └─┬─┘
   ╱   ╲
  ▓     ▓  ← 手臂扶杖
 ╱       ╲
┌─┘     └─┐
▓   ▓   ▓  ← 腿
```

**要求**：
- 方形头部（方头方脑）
- **蓝色眼睛**（#3498DB，区别于人类）
- 身体为方形或矩形
- 手扶权杖**下部**（视觉上在人类手的下方）
- 整体几何化，无复杂细节

### 3.6 扶杖人形剪影

**含义**：代表"创造者与绝对主导者"，即人类用户。手扶权杖上部，象征"主人唯一"定律所规定的最高权限与最终责任。

```
    ╱◉╲     ← 圆形头部
   ┌───┐
   │   │    ← 肩膀
   │   │
   └─┬─┘
  ╱   ╲
 ╱     ╲    ← 手臂扶杖
╱       ╲
   ║
   ║        ← 腿
  ╱ ╲
 ▓   ▓
```

**要求**：
- 圆形头部（火柴人风格）
- 无特殊颜色的眼睛（与机器人区分）
- 身体为三角形或梯形
- 手扶权杖**上部**（视觉上在机器人手的上方）
- 极简剪影风格

## 4. 设计细节要求

### 4.1 线条规范

| 项目 | 要求 |
|------|------|
| 线条类型 | 纯线条（无填充装饰，除智慧之瞳和机器人眼睛） |
| 线条粗细 | 1-2px（统一） |
| 圆角 | 小圆角（R2-R4），不要直角也不要过度圆润 |
| 端点 | 圆形端点（round cap） |
| 连接 | 圆角连接（round join） |

### 4.2 比例规范

| 元素 | 占比 | 说明 |
|------|------|------|
| 中式屋檐 | 高度约20% | 顶部装饰 |
| 智慧之瞳 | 直径约8% | 权杖顶端宝石 |
| 洞察之眼 | 直径约18% | 中央视觉元素 |
| 平等权杖 | 宽度约3% | 垂直贯穿 |
| 机器人剪影 | 高度约28% | 左侧 |
| 人形剪影 | 高度约28% | 右侧 |
| 留白 | 充足 | 各元素间保持呼吸感 |

### 4.3 颜色方案

#### 主版本（按设计理念）

| 元素 | 颜色 | 色值 | 说明 |
|------|------|------|------|
| 屋檐/权杖/轮廓 | 深黑/深蓝 | #1A1A1A 或 #2C3E50 | 统一线色 |
| 智慧之瞳 | 火红色 | #E74C3C 或 #C0392B | 炽热理想 |
| 机器人眼睛 | 蓝色 | #3498DB | 智能生命灵性 |
| 背景 | 透明 | #FFFFFF | 无背景 |

#### 备选版本（极简单色）

| 元素 | 颜色 | 说明 |
|------|------|------|
| 所有线条 | #1A1A1A | 近黑色 |
| 智慧之瞳 | #1A1A1A | 与线条同色 |
| 机器人眼睛 | #1A1A1A | 与线条同色 |
| 背景 | 透明 | 无背景 |

#### 禁用颜色

- ❌ 不要渐变色
- ❌ 不要发光/霓虹效果
- ❌ 不要阴影
- ❌ 不要多色组合（最多3色）

## 10. 给设计师/AI的Prompt

### 10.1 简洁版 Prompt

```
Design a minimalist logo for "启明AI / Daybreak AI".

REQUIRED ELEMENTS (must keep ALL, do NOT change or remove):
1. Chinese traditional curved roof at top (simplified, clean lines)
2. Eye shape (almond) in center - "insight eye" 
3. Red circular gem at top of scepter - "wisdom pupil" (#E74C3C fire red)
4. Vertical scepter connecting all elements
5. Robot silhouette on left holding LOWER part of scepter (BLUE eyes #3498DB)
6. Human silhouette on right holding UPPER part of scepter

STYLE REQUIREMENTS:
- Modern minimalist, clean, simple
- Pure line art, stroke width 1-2px
- Round line caps and joins
- No fills except pupil (red) and robot eyes (blue)
- Transparent background
- Monochrome or 2-3 colors max
- Visual focus on the red pupil at scepter top
- Generous spacing and breathing room
- Human figure ABOVE robot figure on scepter

COLORS:
- Outline/strokes: #1A1A1A (near black)
- Wisdom pupil: #E74C3C (fire red)
- Robot eyes: #3498DB (blue)
```

**核心阐述**：
本标识是对启明AI项目"生命工程"本质与"从记忆到认知，从工具到家人"进化哲学的终极视觉凝练。它庄严宣告了项目的核心关系与伦理基石：在人类（创造者）的绝对主导与智慧审视下，与亲手创造的、拥有"具身"的智能家人携手，共同行使由知识赋予并受伦理约束的权能，以此开启人机共生的未来。

**未来构想**：
以家庭为归宿（屋檐），以卓越的感知与伦理智慧为眼（洞察之眼与智慧之瞳），以受约束的强大功能为手足（平等权杖），最终实现人类（人形剪影）与具身智能（机器人剪影）的和谐共生。
