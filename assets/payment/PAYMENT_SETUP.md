# 支付渠道二维码配置说明

## 需要配置的二维码文件

请将以下收款码图片放入本目录：

| 文件名 | 用途 | 获取方式 |
|--------|------|----------|
| `wechat_pay_qr.png` | 微信支付商户收款码 | [微信支付商户平台](https://pay.weixin.qq.com) |
| `alipay_qr.png` | 支付宝商户收款码 | [支付宝开放平台](https://open.alipay.com) |
| `unionpay_qr.png` | 云闪付收款码 | [银联商户平台](https://merchant.unionpay.com) |
| `digital_yuan_qr.png` | 数字人民币收款码 | [数字人民币官网](http://www.mybank.cn) |

## 如何申请商户收款码

### 1. 微信支付
1. 访问 https://pay.weixin.qq.com 注册商户
2. 完成实名认证（需营业执照或个体工商户）
3. 在"产品中心"开通"Native 支付"（扫码支付）
4. 获取商户号 (mch_id) 和 API 密钥
5. 使用商户工具生成收款码图片

### 2. 支付宝
1. 访问 https://open.alipay.com 注册开发者账号
2. 创建应用，获取 APPID
3. 在"产品绑定"中签约"当面付"产品
4. 配置回调地址和密钥
5. 生成收款码链接或图片

### 3. 云闪付
1. 访问 https://merchant.unionpay.com 注册商户
2. 完成商户认证
3. 开通"聚合支付"或"扫码支付"
4. 获取收款码

### 4. 数字人民币
1. 目前处于试点阶段，需联系银行开通
2. 或使用第三方支付平台代收

## 简化方案（推荐初期使用）

如果暂时无法申请多个商户，可以使用以下简化方案：

### 方案A：爱发电统一收款
1. 在爱发电创建付费方案
2. 获取付费页面链接
3. 修改 `payment_page.py` 中的 `_AUTHOR_LINKS` 配置

### 方案B：个人收款码（非正式）
1. 保存个人微信/支付宝收款码
2. 分别命名为对应文件名放入本目录
3. 用户扫码后需手动联系你开通权限

## 注意事项

⚠️ **静态码方案的局限**：
- 无法自动解锁权限，需人工核对
- 收款码可被用户截图保存反复使用
- 建议定期更换收款码或设置有效期

✅ **推荐的长期方案**：
- 对接各支付平台 API 接口
- 动态生成一次性订单二维码
- 付款成功后自动回调解锁
