# 付费页面资源说明

本目录存放付费引导页面所需的二维码图片。

## 需要放置的图片文件

| 文件名 | 用途 | 说明 |
|--------|------|------|
| `wechat_qr.png` | 微信公众号二维码 | 用户扫码关注公众号 |
| `afdian_qr.png` | 爱发电页面二维码 | 用户扫码赞助开发者 |
| `website_qr.png` | 个人网站二维码 | 用户扫码访问个人官网 |
| `payment_qr.png` | 统一支付二维码 | 用户扫码完成订阅支付（支持支付宝/微信/云闪付） |

## 图片要求

- **格式**: PNG
- **尺寸**: 建议 300x300 像素以上（支付二维码建议 500x500 像素）
- **大小**: 建议不超过 500KB
- **背景**: 透明或白色背景

## 支付二维码说明

`payment_qr.png` 是统一支付二维码，用户扫码后可以在支付页面选择：
- 支付宝
- 微信支付
- 云闪付

### 获取支付二维码

推荐使用第三方支付平台生成统一支付二维码：
1. 易支付
2. 虎皮椒
3. 支付侠
4. 其他聚合支付平台

将生成的支付二维码保存为 `payment_qr.png` 放入本目录即可。

## 可选替代

如果暂时没有图片，可以使用以下占位方案：
- 文件名保持不变
- 代码会自动检测文件是否存在，不存在则不显示该二维码
- 用户仍可通过其他链接访问
